## 接入与设备

- 用户提供型号：`iSMD60D-040-DQBK-AA000`。
- 适配器：CANable，Linux `gs_usb` / SocketCAN `can0`，1 Mbit/s，节点 1。
- 读取设备名称：`iSMD60-AA`；硬件版本：`VD30000U00`；软件版本：`iSMDAS202512240001`。
- 0x1018 厂商标识 `0x300`、产品标识 `0x4644`、修订号 0，与所用 EDS 对应；实际条目数为 3，无序列号子索引。
- 最大速度对象 0x6080 回读 5000；0x607F 回读 89478484。0x607D 正负软限位均为 0，本次未修改驱动器限位。

## 用户要求及执行

用户将初始小位移测试改为**正向相对转动 600 圈，速度指令 600 RPM**。小位移测试没有执行，未自动追加第二次运动。

| 速度指令 / 0x6081 | 600 rpm / 10737418 (`0x00A3D70A`) |
| 加速度 / 0x6083 | 1 rps/s / 1073 |

命令使用独立、被 Git 忽略的 `config/local.live.json`，软件允许范围围绕当时起点和本次终点设置，不修改驱动器持久参数：

```bash
PYTHONPATH=src:/tmp/kinco-pp-deps python3 -m kinco_pp \
  --config config/local.live.json --execute --relative --target 39321600 \
  --velocity 600 --acceleration 1 --deceleration 1
```

这里 `/tmp/kinco-pp-deps` 是本次环境临时安装依赖的位置；常规安装后的操作见 README。该配置依赖当时绝对位置，不能直接复用于下一次 600 圈请求；每次运行会检查起点和终点是否仍在软件范围内。

## 反馈与限制

驱动器确认到位后，程序执行 Halt，保持使能，并联合低速反馈和连续位置稳定确认停稳。实机速度反馈在位置不变时仍存在噪声，本地零速容差设为 0.5 rpm、稳定确认时间 0.3 秒，位置容差为 10 inc。

速度对象 0x6081 已回读为 10737418，与按手册换算的 600 rpm 指令一致。不过，被动监听 SDO 位置响应、按主机时间估算的巡航速度约为 **572～573 rpm**。本次未取得巡航期间的独立 0x606C 采样或外部测速，尚不能确认机械实测转速恰为 600 rpm；反馈单位与主机时基等差异需后续核对。没有自动增加速度指令来补偿，也没有再次启动电机。

## 兼容修复与回归

- 按身份对象实际条目数读取可选字段，保留厂商与产品的严格核对。
- 先核对模式设置回读，再在 Halt 下使能并确认实际模式显示；修复使能前显示仍为 0 引起的超时。
- 停稳判断支持配置速度反馈噪声容差，并要求位置连续稳定，不能只因速度较小就认定静止。
- 23 项单元及虚拟 CAN 测试通过，包括上述兼容场景；自动测试仍不触发真实运动。
